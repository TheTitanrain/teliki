How it works

Three steps from install to fullscreen playback

1
Drop your media
Copy images or videos into the configured media folder. Local path or network share — both work.
2
Teliki scans & caches
Automatically detects new files, copies them to local cache, and builds a fresh playlist — no restart needed.
3
Plays on all screens
Borderless fullscreen playback on every connected display. Supports all screens, primary screen, or a specific display.

Features

Everything you need. Nothing you don’t.

🖥
Multi-monitor
All screens, primary screen, or pick a specific display by index.
🔁
Auto-scan
Polls the media folder on a configurable interval. New files appear without restart.
💾
Local cache
Atomic copy to local cache. Playback continues even if the source goes offline.
🛡
Failure resilient
Broken files are quarantined after repeated failures. Last-known-good playlist preserved on errors.
📹
Images & Video
JPG, PNG, BMP, GIF images and MP4, AVI, WMV video via Windows Media Player.
⚙
INI config
Single appsettings.ini file. Edit intervals, paths, cache limits, and screen mode.

System requirements

Lightweight by design — runs on hardware from 2009

🪟 Windows 7 SP1 or later ⚙ .NET Framework 4.7.2 ▶ Windows Media Player (for video) 🖥 One or more displays
